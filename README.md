# EcoFarm — Version 1.8.2

## О приложении

Данный проект представляет собой десктопное приложение для управления экологическим хозяйством. Приложение позволяет вести учёт работников, заданий, ресурсов и деятельности фермы. Система поддерживает несколько ролей пользователей с различными уровнями доступа, что обеспечивает гибкость в работе с персоналом и управленческими задачами.

## Доступный функционал

На данный момент разработки (Версия 1.8.2) реализованы следующие возможности:

- Ролевая система: администратор, менеджер, рабочий
- Управление сотрудниками и назначение заданий
- Учёт ресурсов и продукции фермы
- Отслеживание выполненных работ и отчётность
- Авторизация и разграничение доступа по ролям

## Технологический стек

- **C# / WinForms** — десктопное приложение для Windows
- **Microsoft SQL Server** — база данных
- **Visual Studio** — среда разработки

## Инструкция по запуску

### 1. Установка базы данных

1. Откройте файл `scriptDB.sql` в Microsoft SQL Server Management Studio
2. Создайте БД с названием `EcoFarmDB`
3. Выполните скрипт для наполнения БД

### 2. Настройка проекта

1. Распакуйте архив с проектом
2. Откройте файл `App.config` и замените значение сервера БД (`DESKTOP-8I0USR8`) на ваше
3. Откройте `EcoFarm.sln` через Visual Studio

### 3. Запуск

- **Стандартный режим:** запустите `EcoFarm\bin\Debug\EcoFarm.exe`
- **Режим отладки:** откройте решение `EcoFarm.sln` в Visual Studio и нажмите F5
